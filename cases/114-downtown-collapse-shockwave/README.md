## Prompt

```text
Grow the collapse already underway in the reference frame: same block, same camera height, same grey light. The shockwave rolls out from the far end, parked-car alarms kick on, glass bows inward and then bursts outward, and a blizzard of paper and dust crosses the empty street. The drone retreats straight back and rises slowly, keeping the avenue centred. Hazy late afternoon, dust-filtered sun, everything past the second block silhouetted.
```

## Why it works

The reference frame fixes the block and the light, so the prompt only has to describe propagation: shockwave, alarms, glass, paper. It states the street is empty, which stops the model filling the frame with people and keeps the shot advertiser-safe. This is also where 480p earns its place: dust and a retreating drone hide the resolution, so it is the case to draft cheaply before spending credits on a 720p re-run.

## Reference image

Upload a wide still of a city block that is already partly collapsing, shot from an elevated position, with no people in frame and no readable shopfront text. Avoid close-ups of damage and avoid any frame with crowds, because the clip will not remove what it is given.
