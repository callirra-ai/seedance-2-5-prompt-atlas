## Prompt

```text
Everything in the reference image, the tailor, the hands, the tape and the shop, stays untouched. The tape is drawn slowly along a shoulder while chalk marks grey wool, and a pin is set and pressed flat with a thumb. The camera swings in a slow arc around the worktable at hand height, keeping the fingers large in frame and the background still. Warm late-afternoon window light falls across the table from the left. Fine 16mm grain, soft contrast.
```

## Why it works

Protecting every element of the reference frame by name is what lets the shot move at all: the model can animate the hands because it has been told the shop must not change. The arc keeps fingers large and the background soft, which hides small rendering errors. One directional window light gives it a single reference point rather than a room to invent.

## Reference image

Upload a close photo of hands at work on fabric, with a tape measure, chalk or a pin in frame. Keep it lit by one directional source so the model extends that light instead of inventing a bright studio, and avoid cluttered backgrounds full of objects it might try to animate.
