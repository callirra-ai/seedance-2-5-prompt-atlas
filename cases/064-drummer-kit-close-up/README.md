## Prompt

```text
Reproduce the reference kit exactly, same drums, same cymbal positions, same room, while the drummer drives a fast fill across the toms, both wrists blurred, then lands hard on the crash. Handheld camera sits tight at drum height and drifts a hand's width closer on the last hit. One hard side key from the left, deep falloff, small glints on the cymbal edges. Gritty concert grade. Audio: a snare crack, a cymbal swell, one kick on the downbeat.
```

## Why it works

A kit reference image does two jobs here: it fixes drum and cymbal positions that a text prompt alone would shuffle every frame, and it lets the request stay tight on hands and wrists. The fill is written as one fast gesture with a clean landing, since a longer roll turns to mush at five seconds. A hard side key from the left keeps the sticks visible against a dark room, and the snare crack gives the edit an obvious sync point.

## Reference image

A clear still of the drum kit, ideally with the player's hands and sticks in frame and the cymbal layout readable. Avoid wide shots where the kit is small in the frame: the model needs the drum positions large enough to keep them from rearranging.
