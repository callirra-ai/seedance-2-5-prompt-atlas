## Why it works

Candlelight is the whole scene, so the prompt names it as part of the locked reference rather than letting the model relight the shot. The action is small and slow — lift, turn, settle — which is exactly the range image-to-video handles convincingly. Dust in the beam supplies the movement, and listing the book's construction keeps the prop from drifting into something generic.

## Reference image

Upload a portrait or full-body reference of the figure in period dress, ideally lit by a single warm source. Avoid flash-lit or hard-lit photos and anything with modern props in frame — the model copies the reference lighting and objects more literally than the prompt.
