## Prompt

```text
One dancer in a concrete parking garage holds the same spot while the edit cuts on every kick drum: jacket changes, angle changes, hair changes, body never leaves frame. The camera never moves, locked at chest height and centred. One caged work lamp on a pillar throws a long shadow forward, floor dark, no fill. Cold industrial grade, slight grain. Audio: a four-on-the-floor kick with a hat on the offbeat.
```

## Why it works

This is a cut-driven case, so everything that normally moves is frozen: camera locked, dancer centred, same spot. What changes on each kick is only costume and angle, which the model can swap without re-solving the body, and that is exactly why the shot survives a hard edit. The work lamp gives one long shadow to read the footwork against, and a four-on-the-floor kick with an offbeat hat tells the edit precisely where each cut belongs. The square frame keeps the pose centred on every social placement.
